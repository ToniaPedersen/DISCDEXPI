DISC Profile MS 1
=================

[DiscProfile RC 1.xml](./DiscProfile%20RC%201.xml) is the current version of the machine-readable DISC Profile.

The other xml files are from the DEXPI Specification 2.0 RC 1; the DISC Profile depends on these files.

[DISC Profile MS 1 HTML.zip](./DISC%20Profile%20MS%201%20HTML.zip) contains a human-friendly HMTL rendering of the DISC Profile. To view:

- Download the archive.

- Extract it locally.

- Open html/index.html in the extracted folder.
